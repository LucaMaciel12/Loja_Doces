# 🍬 Loja de Doces - Banco de Dados SQL Server

Projeto de banco de dados desenvolvido em SQL Server para simular o gerenciamento de uma loja de doces. O projeto contempla a modelagem do banco, criação das tabelas, relacionamentos, inserção de dados e consultas SQL utilizando boas práticas de modelagem relacional.

---

## 📋 Funcionalidades

- Criação do banco de dados
- Criação das tabelas
- Definição de chaves primárias (PK)
- Definição de chaves estrangeiras (FK)
- Inserção de dados
- Consultas utilizando:
  - SELECT
  - WHERE
  - ORDER BY
  - COUNT
  - SUM
  - AVG
  - MAX
  - MIN
  - INNER JOIN
  - GROUP BY

---

## 🗂 Estrutura do Banco

O banco é composto pelas seguintes tabelas:

- Usuários
- Funcionários
- Clientes
- Fornecedores
- Produtos
- Pedidos
- Itens do Pedido

---

## 🛠 Tecnologias

- SQL Server Express
- SQL Server Management Studio (SSMS)

---

## ▶️ Como executar

1. Abra o SQL Server Management Studio.
2. Crie um novo banco ou execute diretamente o script.
3. Execute o arquivo:

```
scripts/loja_doces.sql
```

4. O banco será criado automaticamente com todas as tabelas, relacionamentos, registros de exemplo e consultas.
